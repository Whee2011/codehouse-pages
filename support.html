Frequently Asked Questions

What do I need to use CodeHouse?
A FIDO2 hardware security key (e.g., YubiKey, CanoKey). The iOS app connects via NFC; the macOS app connects via USB.

I forgot my vault PIN / lost my security key. Can you recover my data?
No. There is no recovery mechanism — only your hardware key can decrypt your vault. We strongly recommend enrolling at least one backup key for every vault and keeping offline backups of important files.

How many vaults can I create for free?
The free edition supports one vault named CodeHouse.vault. The Pro upgrade (one-time purchase) unlocks unlimited vaults, custom names/locations, and additional authorized keys.

How do I restore my Pro purchase?
Use the “Restore Purchase” option on the upgrade screen with the same Apple ID used for the original purchase.

Are vault files compatible across devices?
Yes. A .vault file can be moved between iOS, macOS, Windows and Android versions of CodeHouse and opened with any authorized key.

Important: If all authorized hardware keys for a vault are lost, locked, or reset, the data in that vault is permanently unrecoverable — by anyone, including us.

常见问题

使用 CodeHouse 需要什么？
一把 FIDO2 硬件安全密钥（如 YubiKey、CanoKey）。iOS 版通过 NFC 连接；macOS 版通过 USB 连接。

忘记了保险箱 PIN / 丢失了安全密钥，能帮我恢复数据吗？
不能。本软件没有任何恢复机制——只有您的硬件密钥能解密保险箱。强烈建议为每个保险箱授权至少一把备用密钥，并为重要文件保留离线备份。

免费版能创建几个保险箱？
免费版支持一个名为 CodeHouse.vault 的保险箱。专业版（一次性购买）解锁无限保险箱、自定义名称/位置和更多授权密钥。

如何恢复已购买的专业版？
在升级页面使用“恢复购买”，需使用原购买时的 Apple ID。

保险箱文件能跨设备使用吗？
可以。.vault 文件可在 iOS、macOS、Windows 和 Android 版本之间互相拷贝，使用任意一把已授权密钥即可打开。

重要提示：如果某个保险箱的所有授权硬件密钥都丢失、锁定或被重置，其中的数据将永久无法恢复——任何人都无法恢复，包括我们。
